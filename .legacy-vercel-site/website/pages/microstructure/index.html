01 · Choose software

The atlas does not require MRtrix3

Experienced users may treat MesoConnect as an anatomical template inside their own validated tractography pipeline. The public MRtrix3 workflow is a worked example, not a software restriction.

The NIfTI atlas maps can be transformed, thresholded, and used as pathway priors or constraints with MRtrix3, DSI Studio, FSL, DIPY, pyAFQ, or another platform that preserves the intended coordinate space and anatomy. Translate the seed, target, waypoint, exclusion, laterality, and stopping logic into the selected software rather than copying command-line flags literally.

Validate every implementation. Software packages differ in tracking algorithms, interpolation, ROI semantics, streamline termination, coordinate conventions, and defaults. Report the package, version, algorithm, atlas threshold, transforms, constraints, parameters, and QC rules.

02 · Clean tracts

Optional pyAFQ streamline cleaning

The supplied script loads each tractogram against the participant diffusion reference and calls pyAFQ's clean_bundle with 100 resampling points, five cleaning rounds, a distance threshold of 3, a length threshold of 2, and mean-based statistics. These are the study settings, not universal defaults; inspect retained and removed streamlines before accepting them. 

python analysis-code/tracking_and_atlas/pyafq_tract_cleaning.py
  • Edit data_root, tract_root, the tract list, and subject list.
  • Confirm that the reference image matches the tractogram coordinate system.
  • Save counts before and after cleaning and visually inspect both sets.
  • Do not silently exclude failed or very small bundles from group analysis.

03 · Whole-tract summary

Binarize the tract and extract a scalar mean

Use this approach when the scientific question concerns one value per tract. First rasterize the tractogram on the microstructure map's grid, then binarize that density image, mask the scalar map, and calculate the mean. Registration and voxel-grid agreement must be checked before extraction. 

tckmap <TRACT.tck> <TRACT_DENSITY.nii.gz> \
  -template <MICROSTRUCTURE_MAP.nii.gz> -force

fslmaths <TRACT_DENSITY.nii.gz> -bin <TRACT_MASK.nii.gz>

fslmaths <MICROSTRUCTURE_MAP.nii.gz> \
  -mas <TRACT_MASK.nii.gz> \
  <MASKED_MICROSTRUCTURE.nii.gz>

fslstats <MICROSTRUCTURE_MAP.nii.gz> \
  -k <TRACT_MASK.nii.gz> -M

The downloadable whole_tract_microstructure.sh automates these commands and also records voxel count and tract-mask volume. -M excludes zero-valued scalar voxels; use -m instead if zero is a valid value that belongs in the denominator, and report that decision.

04 · NODDI

Fit AMICO-NODDI and save modulated maps

The supplied NODDI.py converts FSL gradients to an AMICO scheme, fits the NODDI model, calculates fit RMSE, and enables doSaveModulatedMaps. The downstream script expects modulated NDI and ODI plus FWF maps. Edit the input roots, output root, subject list, thread count, and b0 threshold for the new dataset. 

python analysis-code/noddi/NODDI.py

Why modulated maps? NDI and ODI describe the tissue compartment. Multiplying those metrics by tissue fraction supplies the numerator contribution for a tissue-weighted regional mean, reducing bias from voxels with little tissue. The final weighted mean requires division by the summed tissue fraction; a plain mean of a modulated map is not the same quantity.

Parker CS, Veale T, Bocchetta M, et al. “Not all voxels are created equal: Reducing estimation bias in regional NODDI metrics using tissue-weighted means.” NeuroImage. 2021;245:118749. doi:10.1016/j.neuroimage.2021.118749.

05 · Nodewise sampling

Preserve spatial variation along the pathway

Whole-tract averages can hide focal effects. The supplied nodewise_noddi.py loads each tract, orients streamlines to a QuickBundles centroid, samples 100 equidistant nodes with Gaussian streamline weights, and writes NDI, ODI, and FWF values to tract-level CSV files plus participant QC plots. 

python analysis-code/noddi/nodewise_noddi.py
  • Run only after tract cleaning and NODDI fitting are complete.
  • Confirm endpoint orientation so node 0 and node 99 have consistent anatomical meaning.
  • Inspect profiles for spikes, missing regions, reversals, and implausible values.
  • Model repeated nodes and multiple-comparison control explicitly in inferential analyses.
