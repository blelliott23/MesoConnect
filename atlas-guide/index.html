01 · Spatial reference

FSL MNI152 1 mm space

The primary public atlas grid is expected to be 182 × 218 × 182 voxels at 1 mm isotropic resolution.

On this site, MNI space means the FSL MNI152 1 mm grid unless a section says otherwise. Native space means the participant diffusion grid used for tractography. In the HCP-style example, MNI atlas masks are transformed to an ACPC-aligned diffusion reference with a standard-to-ACPC deformation field.

Moving image: the atlas map being transformed. Fixed or reference image: the target participant grid that defines output dimensions and voxel size.

02 · Map types

Choose the file by its meaning

File suffixMeaningRecommended use
*_overlap_prop.nii.gz Continuous probability map. Each voxel is the proportion of contributing participants whose binarized tract included that voxel, from 0 to 1. Visualization, threshold decisions, and probability-weighted extraction.
*_thr50.nii.gz Binary 50% threshold map. A voxel is 1 when the tract was present in at least half of contributing participants. Conservative primary atlas for corridor construction and atlas-guided tractography.
mesoconnect_subject_counts.csv One row per tract with its contributing-subject count. Documentation, legends, and denominator checks.

04 · Thresholds

Use overlap thresholds intentionally

Sensitive

25%

Increases participant coverage, but also permits greater spatial overreach.

Primary

50%

The conservative primary atlas used by the worked corridor example.

Strict

75%

Reduces overreach but may omit legitimate interparticipant variation.

The supplied example applies one explicit 2 mm spherical maximum dilation to the binary 50% atlas before corridor construction. Dilation can absorb registration uncertainty, but it also reduces spatial specificity. Record the selected threshold, kernel shape, and radius in every analysis manifest.

05 · Interpolation

Match interpolation to data type

  • Probability maps: use linear interpolation, then apply the intended threshold in native space.
  • Binary masks and labels: use nearest-neighbor interpolation to preserve discrete values.
  • Every output: inspect orientation, grid, and anatomy before extracting values or tracking.
