Worked example · Inferior VTA–NAc

From group atlas to native-space tractography

Use the bilateral 50% MesoConnect atlas as a dilated anatomical corridor, transform it to a participant's diffusion grid, and reconstruct left and right pathways with MRtrix3.

Download annotated script Compare parameter sets

Tutorial steps

  1. 01Identify inputs
  2. 02Dilate the atlas
  3. 03Build the corridor
  4. 04Transform to native
  5. 05Create exclusion
  6. 06Transform endpoints
  7. 07Run tractography
  8. 08Inspect and record

This is an application example, not the atlas-generation pipeline. The supplied example requests 1,000 accepted streamlines, allows 10,000,000 seeding attempts, and uses an FOD cutoff of 0.05. The manuscript atlas was generated with pathway-specific settings, 2,500 accepted streamlines, and up to 25,000,000 attempts. Do not describe the example settings as the manuscript settings.

Every value in angle brackets is a placeholder. Replace it with a real path before running a command; do not type the angle brackets themselves. The downloadable script collects these values at the top so you only need to edit them once.

1

Identify the required files

Confirm every atlas, region, transform, diffusion, and exclusion input.

2

Dilate the 50% atlas maps by 2 mm

Use one explicit spherical kernel so the intended expansion is easy to read and reproduce.

Apply a 2 mm-radius spherical maximum filter to each binary map, then binarize the result. This is clearer than repeating the default -dilM operation, and it states the physical radius directly. Keep the original 50% files unchanged so the analysis remains auditable. 

fslmaths <LEFT_ATLAS_50> -kernel sphere 2 -dilF -bin \
  <ATLAS_OUTPUT_DIR>/left_inferior_vta_nac_mni152_1mm_thr50_dil2mm.nii.gz

fslmaths <RIGHT_ATLAS_50> -kernel sphere 2 -dilF -bin \
  <ATLAS_OUTPUT_DIR>/right_inferior_vta_nac_mni152_1mm_thr50_dil2mm.nii.gz

Dilation is a tradeoff. It can improve sensitivity to small alignment differences while reducing spatial specificity. A 2 mm spherical dilation is not voxel-for-voxel identical to two passes of FSL's default mean dilation. Record the atlas threshold, kernel, and radius.

3

Build the bilateral MNI-space corridor

Combine both dilated atlas paths with bilateral VTA and NAc endpoint regions.

fslmaths <ATLAS_OUTPUT_DIR>/right_inferior_vta_nac_mni152_1mm_thr50_dil2mm.nii.gz \
  -add <ATLAS_OUTPUT_DIR>/left_inferior_vta_nac_mni152_1mm_thr50_dil2mm.nii.gz \
  -add <LEFT_VTA_ROI> -add <RIGHT_VTA_ROI> \
  -add <LEFT_NAC_ROI> -add <RIGHT_NAC_ROI> \
  -bin <ATLAS_OUTPUT_DIR>/inferior_vta_accumbens_inclusion_corridor.nii.gz

The source shell script calls this an “inclusion box.” The tutorial uses inclusion corridor because the mask defines the anatomical route that remains available to tractography.

4

Transform the corridor to native diffusion space

Use the participant brain mask as the reference grid and nearest-neighbor interpolation.

mkdir -p <SUBJECT_OUTPUT_DIR>/roi

applywarp \
  --in=<ATLAS_OUTPUT_DIR>/inferior_vta_accumbens_inclusion_corridor.nii.gz \
  --ref=<NATIVE_BRAIN_MASK> \
  --warp=<MNI_TO_NATIVE_WARP> \
  --out=<SUBJECT_OUTPUT_DIR>/roi/inferior_vta_accumbens_inclusion_corridor.nii.gz \
  --interp=nn

Nearest-neighbor interpolation preserves the binary mask. Immediately overlay the transformed result on the diffusion reference; a command that completes without an error can still produce an anatomically incorrect result.

5

Create the outside-corridor exclusion mask

Invert the corridor, then restrict that inverse to voxels inside the participant brain mask.

fslmaths \
  <SUBJECT_OUTPUT_DIR>/roi/inferior_vta_accumbens_inclusion_corridor.nii.gz \
  -binv \
  <SUBJECT_OUTPUT_DIR>/roi/inverse_inferior_vta_accumbens_inclusion_corridor.nii.gz

fslmaths <NATIVE_BRAIN_MASK> \
  -mas <SUBJECT_OUTPUT_DIR>/roi/inverse_inferior_vta_accumbens_inclusion_corridor.nii.gz \
  <SUBJECT_OUTPUT_DIR>/roi/inferior_vta_accumbens_exclusion_corridor.nii.gz

Passing the final mask to tckgen -exclude prevents accepted streamlines from leaving the atlas-defined route while keeping the exclusion volume limited to the participant brain.

6

Transform the endpoint regions

Warp each VTA and NAc label separately to the same native diffusion grid.

applywarp --in=<LEFT_VTA_ROI> --ref=<NATIVE_BRAIN_MASK> \
  --warp=<MNI_TO_NATIVE_WARP> \
  --out=<SUBJECT_OUTPUT_DIR>/roi/left_vta.nii.gz --interp=nn

applywarp --in=<RIGHT_VTA_ROI> --ref=<NATIVE_BRAIN_MASK> \
  --warp=<MNI_TO_NATIVE_WARP> \
  --out=<SUBJECT_OUTPUT_DIR>/roi/right_vta.nii.gz --interp=nn

applywarp --in=<LEFT_NAC_ROI> --ref=<NATIVE_BRAIN_MASK> \
  --warp=<MNI_TO_NATIVE_WARP> \
  --out=<SUBJECT_OUTPUT_DIR>/roi/left_accumbens.nii.gz --interp=nn

applywarp --in=<RIGHT_NAC_ROI> --ref=<NATIVE_BRAIN_MASK> \
  --warp=<MNI_TO_NATIVE_WARP> \
  --out=<SUBJECT_OUTPUT_DIR>/roi/right_accumbens.nii.gz --interp=nn
  • Overlay all four regions on the native diffusion reference.
  • Confirm that each region is nonempty and on the expected side.
  • Confirm that each seed and target contacts or is reachable within the corridor.
7

Run left and right MRtrix3 tractography

Seed from the VTA, require the ipsilateral NAc, and exclude the outside corridor and opposite hemisphere.

mkdir -p <SUBJECT_OUTPUT_DIR>/tractography

tckgen <WHITE_MATTER_FOD> \
  <SUBJECT_OUTPUT_DIR>/tractography/left_inferior_vta_nac.tck \
  -seed_image <SUBJECT_OUTPUT_DIR>/roi/left_vta.nii.gz \
  -seed_unidirectional -select 1000 -seeds 10000000 \
  -include <SUBJECT_OUTPUT_DIR>/roi/left_accumbens.nii.gz \
  -exclude <SUBJECT_OUTPUT_DIR>/roi/inferior_vta_accumbens_exclusion_corridor.nii.gz \
  -exclude <RIGHT_HEMI_MASK> \
  -fslgrad <BVEC_FILE> <BVAL_FILE> \
  -cutoff 0.05 -stop -nthreads 16 -force

tckgen <WHITE_MATTER_FOD> \
  <SUBJECT_OUTPUT_DIR>/tractography/right_inferior_vta_nac.tck \
  -seed_image <SUBJECT_OUTPUT_DIR>/roi/right_vta.nii.gz \
  -seed_unidirectional -select 1000 -seeds 10000000 \
  -include <SUBJECT_OUTPUT_DIR>/roi/right_accumbens.nii.gz \
  -exclude <SUBJECT_OUTPUT_DIR>/roi/inferior_vta_accumbens_exclusion_corridor.nii.gz \
  -exclude <LEFT_HEMI_MASK> \
  -fslgrad <BVEC_FILE> <BVAL_FILE> \
  -cutoff 0.05 -stop -nthreads 16 -force
8

Inspect, retain, and report

Treat visual quality control and provenance as required outputs.

  • Inspect the thresholded and 2 mm-sphere-dilated atlas in MNI space.
  • Inspect the native corridor, seed, target, and exclusion masks over the diffusion reference.
  • Confirm that the corridor remains connected to the intended seed and target.
  • Confirm that reconstructed streamlines remain ipsilateral and follow the expected trajectory.
  • Record the accepted streamline count and whether the seeding-attempt ceiling was reached.
  • Save at least one corridor overlay and one streamline QC image for each participant.
  • Save the exact command, software versions, atlas version, threshold, dilation kernel and radius, and any deviations.

Do not generalize by filename substitution alone. The other six pathways require their manuscript-specific seed, waypoint, target, exclusion, length, angle, and FOD-cutoff logic.
